## 📌 Project Overview

This application provides a seamless local two-player Tic-Tac-Toe experience. It features real-time win/draw algorithms, immediate board state resets, and a clean user-centric UI.

| Feature                | Description                                              |
| :--------------------- | :------------------------------------------------------- |
| 🎮 **Gameplay**        | Turn-based classic 3x3 grid for 2 players (X and O)      |
| ⚡ **Real-time Logic** | Instant evaluation of 8 possible winning combinations    |
| 🔄 **Reset & Replay**  | Quick restart functionality to reset the state instantly |
| 📱 **Responsive UI**   | Fluid CSS styling adapted for both Desktop and Mobile    |

---

## 🛠️ Tech Stack & Architecture

- **`tictac.html`** – Provides clean, semantic structure for the game canvas and control panel.
- **`tictac.css`** – Custom CSS grid layout, hover effects, and responsive breakpoints.
- **`tictac.js`** – Handles state management, turn switching, win/draw verification, and DOM updates.

```text
📦 Game-tic-tac-toe
├── 📄 tictac.html    # Core markup
├── 🎨 tictac.css     # Styling & Layouts
└── ⚡ tictac.js      # Game logic engine
```
